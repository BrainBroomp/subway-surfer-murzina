# Кирпичики на колёсах — GitHub Pages

Это готовая статическая сборка игры. Node.js, `npm install` и собственный сервер не нужны.

## Публикация

1. Создайте репозиторий GitHub или выберите существующий. Добавьте **содержимое** папки `brick-run-pages` в корень ветки `main`: `index.html`, `.nojekyll`, папки `assets/` и `models/`, а также файлы `.json`. Не помещайте `index.html` в дополнительную вложенную папку. Если ваша основная ветка называется иначе, используйте её вместо `main`.
2. Откройте **Settings → Pages**. В разделе **Build and deployment** для **Source** выберите **Deploy from a branch**, затем ветку `main` и папку **`/ (root)`**. Нажмите **Save**.
3. Когда GitHub завершит развёртывание, откройте ссылку из **Settings → Pages**. Для обычного репозитория это `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

В сборке используются относительные пути, поэтому она работает и на адресе с именем репозитория в пути. Не открывайте `index.html` напрямую через `file://`: браузер загружает модели и настройки по HTTP(S).

Модель героини создана по фотографии и входит в файлы сайта. Если сайт открыт всем, посетители смогут скачать модель. Публикуйте её только если это допустимо для человека на фото.

[Инструкция GitHub по настройке источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
